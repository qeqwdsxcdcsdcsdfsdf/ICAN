                    人脸+GPS考勤系统 - 运行文档
================================================================================

一、项目概述
----------
本系统是一个基于Spring Boot + Vue的人脸+GPS考勤管理系统，包含以下模块：
- 后端服务：Spring Boot框架，提供RESTful API
- 前端管理：Vue框架，提供管理后台界面

二、环境要求
------------
1. Java JDK 1.8+
   - 必须配置 JAVA_HOME 环境变量

2. Node.js 14+
   - 建议使用 npm 或 yarn 作为包管理器

3. MySQL 5.7+
   - 数据库名称：face_attendance_gps
   - 默认用户名：root
   - 默认密码：123456

三、一键启动
------------
直接双击运行项目根目录下的 start.bat 文件，系统将自动完成以下操作：

1. 检查环境配置（Java、Node.js）
2. 清理端口占用（8080、8082）
3. 启动后端服务（端口8082）
4. 启动前端服务（端口8080）

四、服务访问地址
----------------
- 前端管理后台：http://localhost:8080
- 后端API服务：http://localhost:8082

五、登录账号
------------
默认管理员账号：
- 用户名：admin
- 密码：123456

默认员工账号：
- 用户名：S001
- 密码：123456

七、端口说明
------------
- 前端服务：8080（用户访问端口）
- 后端服务：8082（API服务端口）
- MySQL：3306（数据库端口）

八、常见问题
------------
1. 端口占用问题
   - 系统启动时会自动清理8080和8082端口
   - 若清理失败，请手动关闭占用端口的程序

2. 数据库连接失败
   - 请确保MySQL服务已启动
   - 确认数据库名称为：face_attendance_gps
   - 确认用户名和密码正确

3. JAVA_HOME未配置
   - 请在系统环境变量中配置JAVA_HOME
   - 指向JDK安装目录

4. 前端页面无法访问
   - 请确认前端服务已启动
   - 检查端口8080是否被占用

九、手动启动方式
----------------
如需手动启动，可以按以下步骤操作：

1. 启动后端服务：
   cd 02-SpringBoot-Server
   mvnw.cmd spring-boot:run

2. 启动前端服务：
   cd 03-PC-Admin-Vue
   npm run dev

十、功能模块
------------
1. 管理员管理：管理员账号的增删改查
2. 员工管理：员工信息的管理和维护
3. 考勤签到：员工打卡签到功能（含人脸+GPS定位）
4. 考勤记录：查询和统计考勤数据
5. 定位配置：配置考勤地点的GPS范围
