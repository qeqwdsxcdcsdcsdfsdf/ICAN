# 人脸+GPS双重校验考勤系统 - 部署文档

## 环境要求

### 后端服务
- JDK 1.8+
- MySQL 5.7+
- Maven 3.6+

### 管理后台
- Node.js 14+
- npm 6+

### Android APP
- Android Studio 2022+
- Android SDK 24+

## 部署步骤

### 1. 数据库配置

创建数据库并导入SQL：

```sql
CREATE DATABASE face_attendance_gps DEFAULT CHARACTER SET utf8mb4;
USE face_attendance_gps;
source doc/database.sql;
```

### 2. 后端服务配置

修改 `02-SpringBoot-Server/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/face_attendance_gps?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
    username: your_username
    password: your_password
```

启动服务：

```bash
cd 02-SpringBoot-Server
mvn spring-boot:run
```

服务启动后访问：http://localhost:8080

### 3. 管理后台配置

安装依赖并启动：

```bash
cd 03-PC-Admin-Vue
npm install
npm run dev
```

访问地址：http://localhost:8081

### 4. Android APP配置

1. 使用Android Studio打开 `01-Android-App` 目录
2. 修改 `app/src/main/java/com/attendance/api/ApiService.java` 中的 `BASE_URL` 为后端服务地址
3. 运行APP到模拟器或真机

## 接口说明

### 管理员接口
- POST /api/admin/login - 登录

### 员工接口
- POST /api/staff/login - 登录
- POST /api/staff/face/register - 人脸注册
- GET /api/staff/list - 获取员工列表

### 签到接口
- POST /api/sign/in - 签到（人脸+GPS）
- GET /api/sign/records - 获取签到记录

### 定位配置接口
- GET /api/location/config - 获取配置
- POST /api/location/config - 更新配置
- POST /api/location/check - 校验定位

## 注意事项

1. 确保MySQL服务已启动，端口为3306
2. Android APP需要授予定位和相机权限
3. 后端服务默认端口为8080，确保端口未被占用
4. 生产环境请修改默认密码并添加HTTPS支持
