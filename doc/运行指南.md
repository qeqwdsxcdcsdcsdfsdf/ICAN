# 人脸+GPS双重校验考勤系统 - 运行指南

## 一、项目概述

本项目是一个人脸+GPS双重校验考勤系统，包含三端：
- **Android APP**：员工打卡端（人脸采集+GPS定位）
- **SpringBoot后端**：业务逻辑处理（人脸比对+GPS校验）
- **Vue管理后台**：管理员管理端（员工管理+考勤记录+定位配置）

## 二、环境准备

### 2.1 已安装环境检查

| 工具 | 版本要求 | 检查命令 | 当前状态 |
|------|----------|----------|----------|
| Java | 1.8+ | `java -version` | ❌ 未安装 |

### 2.2 安装Java JDK

1. **下载地址**：https://www.oracle.com/java/technologies/downloads/#java8-windows
2. **安装步骤**：
   - 双击安装包，选择安装路径（建议：`C:\Program Files\Java\jdk1.8.0_391`）
   - 配置环境变量：
     - 新建 `JAVA_HOME`：`C:\Program Files\Java\jdk1.8.0_391`
     - 编辑 `PATH`：添加 `%JAVA_HOME%\bin`
3. **验证安装**：
   ```bash
   java -version
   ```
   输出示例：
   ```
   java version "1.8.0_391"
   Java(TM) SE Runtime Environment (build 1.8.0_391-b13)
   Java HotSpot(TM) 64-Bit Server VM (build 25.391-b13, mixed mode)
   ```

### 2.3 安装Maven

1. **下载地址**：https://maven.apache.org/download.cgi
2. **安装步骤**：
   - 解压到 `C:\apache-maven-3.9.6`
   - 配置环境变量：
     - 新建 `MAVEN_HOME`：`C:\apache-maven-3.9.6`
     - 编辑 `PATH`：添加 `%MAVEN_HOME%\bin`
3. **验证安装**：
   ```bash
   mvn -version
   ```
   输出示例：
   ```
   Apache Maven 3.9.6 (bc0240f3c744dd6b6ec2920b3cd08dcc295161ae)
   Maven home: C:\apache-maven-3.9.6
   Java version: 1.8.0_391, vendor: Oracle Corporation
   ```

### 2.4 安装MySQL

1. **下载地址**：https://dev.mysql.com/downloads/installer/
2. **安装步骤**：
   - 运行安装程序，选择 "Developer Default" 类型
   - 设置root密码为 `root`（与配置文件一致）
   - 确保MySQL服务端口为3306
3. **验证安装**：
   ```bash
   mysql -u root -p
   ```
   输入密码 `root` 后进入MySQL命令行。

4. 成功后进入管理后台首页

### 6.2 登录失败排查

如果登录失败，按以下步骤排查：

#### 步骤1：检查后端是否启动

打开浏览器访问：http://localhost:8080/api/admin/login

如果显示"无法访问此网站"，说明后端未启动或端口被占用。

#### 步骤2：检查数据库连接

查看后端启动日志，搜索 "ERROR" 或 "Connection"：

- 如果出现 `Access denied for user 'root'@'localhost'`：检查数据库用户名密码
- 如果出现 `Unknown database 'face_attendance_gps'`：检查数据库是否创建
- 如果出现 `Communications link failure`：检查MySQL服务是否启动

#### 步骤3：检查密码加密

数据库中密码存储的是MD5哈希值，后端登录时会对输入密码进行MD5加密后比对。

验证MD5加密是否正确：

```bash
# 在线工具验证：123456 的MD5值应为 e10adc3949ba59abbe56e057f20f883e
```

#### 步骤4：检查前端代理配置

查看 `vue.config.js`：

```javascript
module.exports = {
  devServer: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',  // 后端地址
        changeOrigin: true
      }
    }
  }
}
```

#### 步骤5：浏览器开发者工具调试

按 F12 打开开发者工具，切换到 "Network" 标签：

1. 点击登录按钮
2. 查看 `/api/admin/login` 请求
3. 检查：
   - 请求URL是否正确
   - 请求方法是否为 POST
   - 请求体是否包含 `username` 和 `password`
   - 响应状态码是否为 200
   - 响应内容是否包含 `{"success":true,...}`

|------|----------|

| 人脸注册 | 采集人脸特征 |
| 考勤记录 | 查看个人考勤记录 |
| 设置 | 个人信息、退出登录 |

### 7.3 核心校验逻辑

```
签到流程：
1. 获取GPS定位（经纬度）
2. 采集人脸照片并提取特征
3. 上传到后端进行双重校验
   - GPS校验：计算与中心点距离是否在允许范围内
   - 人脸校验：比对当前人脸与注册人脸是否匹配
4. 双重校验通过 → 签到成功
   任一校验失败 → 签到失败，返回失败原因
```

## 八、常见问题及解决方案

### Q1：端口被占用

**问题**：启动时提示端口8080或8081已被占用

**解决方案**：

- 8080端口（后端）：修改 `application.yml` 中的 `server.port`
- 8081端口（前端）：修改 `vue.config.js` 中的 `port`

或者关闭占用端口的进程：

```bash
# Windows
netstat -ano | findstr :8080
taskkill /PID <进程号> /F
```

### Q2：MySQL连接失败

**问题**：后端启动时无法连接MySQL

**解决方案**：

1. 确认MySQL服务已启动：
   ```bash
   net start MySQL
   ```

2. 确认数据库已创建：
   ```sql
   SHOW DATABASES;
   ```

3. 确认用户名密码正确：
   ```bash
   mysql -u root -proot
   ```

### Q3：登录失败，提示"密码错误"

**问题**：输入正确密码但提示密码错误

**解决方案**：

1. 确认数据库中存储的是MD5哈希值
2. 确认后端代码已修复（已添加MD5加密）
3. 重启后端服务使修改生效

### Q4：前端启动后无法访问后端接口

**问题**：登录时网络请求失败

**解决方案**：

1. 确认后端服务已启动（访问 http://localhost:8080）
2. 确认 `vue.config.js` 代理配置正确
3. 检查浏览器控制台是否有CORS错误

### Q5：Maven下载依赖慢

**问题**：`mvn spring-boot:run` 时下载依赖很慢

**解决方案**：

配置Maven镜像源，修改 `~/.m2/settings.xml`：

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```
